# The Crownx Studios (Vite + React + TS + Tailwind + GSAP)

    npm install
    npm run dev
    npm run build

Photos: add jpgs to `public/photos/` (work-1..6.jpg, about-1..3.jpg). Gradients show until then.
Contact: edit WHATSAPP / EMAIL in `src/shared.tsx`, WORK / SERVICES / PLANS in `src/Sections.tsx`.
SEO: replace `https://example.com` in `index.html`, `public/robots.txt`, `public/sitemap.xml`.
